Social Arbitrage · 產品藍圖

訊號窗口

一套把 Chris Camillo 的社交套利方法，重寫成 2026 年可執行系統的規格書。不是複製他的工具，是複製他的思考順序——並補上他當年沒有的語意運算能力。

Camillo 當年的 alpha 來自「誰先看到」。那個窗口已經被機構買走了——包括他自己賣掉的 TickerTags。今天散戶還握得住的優勢，是「誰真的讀懂」：一萬則留言在講什麼、是不是購買意圖、對應到哪家公司的哪條產品線、佔營收幾 %。速度差正在歸零，語意差正在打開。這個 app 只賭後者。

優勢遷移

同一套邏輯，不同的稀缺資源

兩個時代要問的問題完全一樣（這會影響股價嗎？市場知道了嗎？），但「答得出來」所需要的稀缺能力換了位置。系統裡每一個模組都要對準右邊那欄。

2007 – 2015　人力優勢
  • 稀缺的是注意力：肯每晚泡工程師論壇數 AWS 提及次數的人很少
  • 關鍵字提及量本身就是 alpha，Google Trends 幾乎沒人拿來看盤
  • 華爾街的資料延遲以「週」計（保險理賠報告、通路調查）
  • 網紅影響力完全在分析師的認知盲區之外
2026　語意優勢
  • 稀缺的是詮釋：提及量人人有，但「這些人是要買、要罵、還是在玩梗」沒人分得清
  • 另類資料已商品化，量化基金買同一批 feed，純速度賽你必輸
  • 真正的難點變成營收映射：趨勢紅了，但只佔母公司營收 3%，多數散戶死在這
  • LLM 讓一個人能做過去一個研究團隊的閱讀量——這是新的不對稱
系統架構

五層管線

順序不能換。每天排程跑一次，任何一層擋下來的假說就不進雷達——這個「擋下來」的紀律，比找到訊號更重要。

01

廣度優先，別只盯股票討論區——股票討論區的資訊照定義已經是「市場知道的」。要抓的是消費現場：留言、評論、排行榜、徵才職缺。

02

語意　主題浮現，而不是關鍵字爆量

最關鍵的升級。關鍵字警報有個死結：新趨勢的關鍵字你事先不知道。改成把留言 embedding、做流式分群，偵測「一個過去不存在的主題群突然長出來」。再用 LLM 對每群標註情緒、購買意圖、是真需求還是迷因。

embedding + HDBSCAN
時序 z-score / STL
Claude 標註意圖分類
輸出：主題卡 + 加速度
03

映射　趨勢 → 可交易標的 → 營收曝險

趨勢對誰有利、佔它營收多少、有沒有更純的標的（供應商、代工、原料）。必須輸出一個百分比，低於門檻直接丟掉。這層擋掉的爛點子會比其他四層加起來還多。

Claude 讀 10-K / 年報
抽 segment revenue
→ ticker + 曝險 %
低於門檻自動退件
04

濾網　市場已經知道了嗎

Camillo 的第二問，自動化版。掃券商報告、新聞量、法說會逐字稿有沒有提過、選擇權隱含波動、以及股價是否已經先動。輸出一個 0–100 的「已知度」，這是整個 app 的靈魂欄位。

新聞 / 分析師覆蓋
法說逐字稿檢索
IV 與價量是否已反應
→ 已知度分數
05

紀律　假說日誌與校準

唯一能讓你逐年變強的一層。進場前強制寫下：我看到什麼、為什麼華爾街看不到、什麼證據會證明我錯、預計多久兌現。到期系統強制回顧並計分。三個月後你會知道自己在哪類趨勢上真的有邊。

假說卡 + 到期提醒
事後 Brier 分數
分類命中率
→ 個人校準報告

實作順序

三階段，先證明你有邊再寫程式

最常見的失敗是先花三個月做爬蟲、資料庫和圖表，然後才發現自己根本挑不出好假說。順序要反過來。

階段 0第 1–4 週

零程式碼，純手動

  • 一個 Notion 表加上 Claude 對話，每天手動把五層問一遍
  • 只做紙上交易，不下單，目標是累積 20–30 筆假說
  • 真正的產出：搞清楚你的領域優勢在哪，也就是你天生就懂的那個圈子
階段 1第 2–3 個月

一個垂直領域自動化

  • 只鎖階段 0 命中率最高的那一類，別想做全市場
  • Python 加排程：Reddit / YouTube / Trends 三源，每日跑分群與異常偵測
  • Claude API 做意圖標註與營收曝險抽取，結果寫進 SQLite 或 Postgres
  • 介面先做「訊號雷達 + 假說日誌」兩頁就好
階段 2第 4 個月起

補上濾網與校準

  • 已知度分數（新聞覆蓋、法說逐字稿、IV、價量），這是最能提升勝率的一塊
  • 時間差圖與校準報告上線，用歷史資料回測你的門檻設定
  • 推播規則：只有「曝險高於門檻，且已知度低於 40」才准吵你
誠實的部分

在開始之前要接受的四件事

倖存者偏差

用同樣方法賠光的人不會出書，也不會被寫進《Unknown Market Wizards》。他的高年化報酬是自陳數字，且來自高度集中加槓桿的部位。方法可學，結果不可假設。

窗口本來就在縮

另類資料的商品化，有一部分正是他自己推動的。設計時要假設「純聲量訊號」的半衰期只會越來越短，價值必須來自語意層和映射層。

LLM 會很有說服力地講錯話

營收曝險那層一定要能點回原始財報段落。看起來合理但沒有出處的 ticker 映射，是最貴的一種幻覺。

資料與合規邊界

爬蟲要看各站服務條款，個資不要落地。任何來自非公開管道的資訊都不能拿來交易——社交套利吃的是公開資訊的解讀差，不是取得差。

這份規格書描述的是研究工具，不是投資建議。所有分數與門檻都需要用你自己的實測資料校準。
