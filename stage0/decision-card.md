# 決策卡模板

**這張卡機器填 90%，你只填兩格。**

原本的 `hypothesis-card.md` 是給人從頭手寫的，留著當參考格式。
自動巡邏產出的卡用這一份 —— 送到你眼前時，01–04 已經填好了，
而且已經通過已知度濾網（見 `auto-flow.md`）。

---

```markdown
# [代號] [公司] — [一句話]

狀態：待你決策
開卡日：YYYY-MM-DD
已知度：__ / 100 　🟢 <30 ／ 🟡 30–59

## 機器已填 ↓（你只需要讀，不需要寫）

### 01 看到什麼
- 具體事實：
- 來源 1：（連結）
- 來源 2：（連結，**獨立於來源 1**）
- 跟三個月前基線的差異：

### 02 訊號性質
- 類型：擴產 / 抽單 / 人力異動 / 新產品需求
- 是新冒出來的主題，還是舊主題變大聲：

### 03 映射（草稿，可能有錯）
- 標的：
- 營收曝險：__%
- **財報出處**：（哪份、第幾頁、原文段落）
  - ⚠️ 標「未驗證」= 機器抽不到原文，這個數字不可信

### 04 已知度拆解
- 法說會提過：是 / 否　(+40 / 0)
- 媒體報導篇數：__ 篇　(+30 / +15 / 0)
- 券商覆蓋度：　(+20 / 0)
- 近一月漲幅／處置股：　(+20 / 0)
- 合計：__ / 100

---

## 你要回的兩題 ↓

### ❶ 這是真的異常嗎？ 　[ 是 / 否 ]

判斷依據只有一個：**你懂不懂這個圈子。** 同學在哪實習、學長姐在哪上班、
校園徵才誰在搶人、你看得懂的技術規格 —— 機器沒有這些。

答「否」→ 卡直接歸檔成死卡，死因寫「人工否決」。結束，不用填下面。

### ❷ 什麼會證明我錯？

> 寫成具體、可觀察、有日期的條件。例：
> 「若 10/10 公告的 9 月營收月增率低於 5%，這張卡就是錯的。」

答案：

到期日：YYYY-MM-DD（綁哪次月營收或財報 —— 機器會照這個日期提醒你）

---

## 到期回顧（到期日機器會把這張卡推回來）

### ❸ 對還是錯？　[ 對 / 錯 / 不明 ]

實際發生什麼：
如果錯，錯在哪一層：訊號 / 映射 / 濾網 / 時機

> 這一題**不能給機器裁決**。校準分數的唯一來源就是你的裁決；
> 機器裁自己，校準報告永遠滿分，那一頁就廢了。
```

---

## 你的總工時

- 沒訊號的日子：**0 分鐘**（機器寫日誌，不通知你）
- 有卡的日子：**約 3 分鐘**（讀機器填好的，回兩題）
- 到期日：**約 2 分鐘**（回第三題）

原本的做法是每天 15–30 分鐘手寫，其中九成花在最後會被 04 層丟掉的候選上。
