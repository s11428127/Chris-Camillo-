複製這個檔到 `log/YYYY-MM-DD-標的-一句話.md`，填完再說。
**狀態欄一開始就要填 `紙上交易`。階段 0 不下單。**

## 死掉的卡也要留

沒通過檢查清單的，一樣開一張，但只填到死掉那層，加一行：

```
❌ 死因：[來源即市場共識 / 雜訊 / 曝險不足 / 已知度過高]
```

放進 `log/` 一樣命名。三個月後這些卡會告訴你：你最常在哪一層失手。
