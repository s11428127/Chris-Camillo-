訊號窗口

把 Chris Camillo 的社交套利方法，重寫成 2026 年可執行的系統。不是複製他的工具，是複製他的思考順序，並補上他當年沒有的語意運算能力。

Camillo 當年的 alpha 來自「誰先看到」。那個窗口已經被機構買走了 —— 包括他自己賣掉的 TickerTags。今天散戶還握得住的優勢，是「誰真的讀懂」：一萬則留言在講什麼、是不是購買意圖、對應到哪家公司的哪條產品線、佔營收幾 %。

速度差正在歸零，語意差正在打開。這個專案只賭後者。

先讀這個

三句話版本

1　趨勢真的還不夠

要佔那家公司營收夠大，股價才會動。趨勢看對但買到「這件事對它不痛不癢」的公司，是散戶最常見的死法。

2　市場知道的沒價值

新聞報過了、股價已經漲過了，就丟掉。消息是真的沒有用，錢已經被賺走了。

3　先用假錢跑三個月

你現在還不知道自己準不準。紙上交易累積 20–30 筆假說，證明有邊之後再談真的。

為什麼在台灣做

台灣人有三個別人拿不到的東西

台灣的消費趨勢常常對不到可交易標的 —— 台股以製造與半導體為主，純消費股少。但換個角度看，這裡有三個美國散戶完全複製不了的優勢。

A

繁中社群是機構盲區

量化基金對英文 Reddit、TikTok 的覆蓋已經飽和，但幾乎沒人在對 PTT、Dcard、巴哈做語意分析。這是還沒被套利掉的資訊差。

B

站在供應鏈上游

竹科的徵才、加班、抽單傳聞，時間上比美國分析師早。這同時對應得到台股與美股半導體。

C

每月 10 日的月營收

全球罕見的高頻硬數據。你這個月的判斷，下個月 10 號就知道對不對 —— 學習速度比美股季報快三倍。

系統架構

五層管線

順序不能換。任何一層擋下來的假說就不進雷達 —— 這個「擋下來」的紀律，比找到訊號更重要。

層做什麼階段 0 怎麼做
01 採集消費現場與供應鏈現場的原始文本、榜單、職缺自己翻 PTT、104
02 語意主題浮現取代關鍵字警報；判斷購買意圖自己讀，判斷是不是新的
03 映射趨勢 → 標的 → 營收曝險 %，低於門檻退件翻年報找產品比重表
04 濾網「市場已經知道了嗎」→ 已知度分數 0–100Google + 法說逐字稿 + 看股價
05 紀律假說日誌 + 到期強制回顧 + 個人校準寫卡、設到期日

第 03、04 層的工作是「否決」，不是發現。 它們擋掉的爛點子會比其他三層加起來還多。這兩層做得越狠，你的勝率越高。

關鍵技術升級

主題浮現，而不是關鍵字爆量

關鍵字監控有個死結：新趨勢的關鍵字你事先不知道。所以不做 keyword alert，改成把留言 embedding 後做流式分群，偵測「一個過去不存在的主題群突然長出來」。

這是 Camillo 當年做不到、而現在一個人就能做的事 —— 也是這個專案跟市面上所有聲量監測工具最大的差別。

實作順序

先證明你有邊，再寫程式

最常見的失敗是先花三個月做爬蟲和圖表，然後才發現自己根本挑不出好假說。順序要反過來。

階段 0 · 現在

零程式碼

用五層檢查工具手動跑，累積 20–30 筆假說。全部紙上交易。產出是「知道自己準不準」。

階段 1

一個領域自動化

只鎖命中率最高的那一類。Python 排程接三個源，Claude API 做意圖標註與曝險抽取。

階段 2

濾網與校準

已知度分數自動化、時間差圖、個人校準報告。推播只在「曝險夠高且已知度夠低」時才響。

誠實的部分

開始之前要接受的四件事

倖存者偏差

用同樣方法賠光的人不會出書。他的高年化是自陳數字，且來自高度集中加槓桿的部位。方法可學，結果不可假設。

窗口本來就在縮

另類資料的商品化有一部分正是他推動的。純聲量訊號的半衰期只會越來越短。

AI 會很有說服力地講錯話

營收曝險一定要能點回財報原文段落。看起來合理但沒有出處的數字，是最貴的一種幻覺。

資料與合規邊界

爬蟲看服務條款，個資不落地。社交套利吃的是公開資訊的解讀差，不是取得差。

下一步

今天就能開始

  1. 花 10 分鐘讀名詞速成的第一區（只讀第一區就夠）
  2. 花 5 分鐘看範例卡，感覺一下要寫到多細
  3. 翻 PTT Tech_Job 最近一週，找一則讓你「咦？」的討論
  4. 打開五層檢查工具，跑一遍，產出你的第一張卡

第一張卡多半會死在半路。那是正常的，也是重點。 死掉的卡跟活的一樣值錢 —— 三個月後它們會告訴你，你最常在哪一層失手。
